# أدلة المرحلة الأولى المحلية

هذه صور مكونات الإدارة الفعلية داخل بيئة مراجعة محلية. الاستعادة وتهيئة المسودة تستخدمان أفعالهما وRPC الفعليين في PostgreSQL معزول. صلاحية الجلسة ولقطة مصدر الرئيسية محقونتان للاختبار؛ ليست جلسة مالكة إنتاجية. قائمة الاختيار مزود اصطناعي واضح، وحفظ اختيارها يبقى في ذاكرة خادم الاختبار؛ لا ننسبه إلى حفظ منتج في قاعدة البيانات.

- `restore-conflict-desktop.jpg`: رفض استعادة مبنية على نسخة أقدم، مع بقاء التعديل الجديد وعداد تدقيق صفر.
- `choice-read-failure-desktop.jpg` و`choice-read-failure-mobile-390.jpg`: الخطأ واضح والاختيار محفوظ.
- `home-compare-desktop.jpg`: المقارنة الفعلية، بما فيها صورة المكتب ومصدر السطر المهني بدل نص القالب.
- `home-compare-390.jpg` و`home-compare-768.jpg` و`home-compare-1024.jpg` و`home-compare-1440.jpg`: مقارنة الأقسام الستة والصور المرجعية عند العروض الأربعة.
- `responsive.json`: قياسات DOM، دون بيانات عميلات.
- `verification.json`: نتائج الفحص النهائية المحددة النطاق.

قد لا تُحمّل الصور الكسولة الواقعة أسفل الشاشة قبل تمريرها؛ لا نستنتج فشل أصل صورة من لقطة طويلة وحدها. لا تمثل هذه اللقطات قبول Chrome مستقل أو أجهزة فعلية أو اختبار نشر على Cloudflare. استُبدلت اللقطات الأولية التي سبقت تصحيح مصدر الاعتمادات بلقطات المقارنة النهائية.
