# صور وفحص مكونات المحررات — 2026-10-17

هذه **مكونات التطبيق الفعلية داخل عارض محلي** ببيانات مصطنعة. كل محاولة حفظ تُرفض صراحة. لا توجد جلسة مخولة أو اتصال Auth/PostgREST/Storage في هذا العرض؛ الصور لا تثبت حفظ قاعدة أو قبول تكامل.

| الفحص | النتيجة |
|---|---|
| الهاتف 390×844، التابلت 768×1024، الحاسوب 1440×1000 | ناجح: عرض نافذة الحجز داخل الشاشة، دون تجاوز أفقي |
| Shift+Tab من عنوان النافذة ثم Tab من آخر زر | ناجح: التركيز يبقى في النافذة، ويلتف بين آخر إجراء والإغلاق |
| Escape ثم إعادة الفتح | ناجح: يعود التركيز لزر الفتح وتبقى مدخلات الحجز والدرس |
| رفض الحفظ في الحجز ووصف البحث | ناجح للمكوّن: رسالة رفض واضحة، المدخلات باقية والأزرار متاحة لإعادة المحاولة؛ لا نجاح وهمي |
| تكديس حقول النص والمدة وأمثلتها | عُرضت في الهاتف والتابلت والحاسوب، مع حقول مقروءة |
| صور الصفحة الطويلة الكاملة | تعذر التقاط موثوق من أداة المتصفح؛ أزيلت الصور ذات أبعاد/تركيب غير صحيح، واحتُفظ بلقطات النافذة المقروءة |
| صفحة المنهج كاملة ومحتواها بعد تحديث مزود حقيقي | غير منفذ، يتطلب بيئة Supabase الاختبارية |
