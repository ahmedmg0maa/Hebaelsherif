# أدلة تصحيح الاختيارات والقبول المحلي

هذه بيانات اختبار أصلية معزولة، دون عميلات أو كلمات مرور أو مفاتيح. جميع صور الإدارة هنا **مكوّنات فعلية داخل محمل اختبار** بصلاحية محقونة ومحول SQL محلي؛ ليست جلسة Supabase مقبولة ولا دليلًا على PostgREST أو Storage أو المعاينة الخاصة. راجعي [التقرير](../ADMIN_PHASE_ONE_ACCEPTANCE_AR.md) لتصنيف النتائج والعوائق.

| الملف | ما يثبته |
|---|---|
| `enter-no-write.json` | نموذج صالح، بحثا Enter، لا طلب حفظ ولا كتابة في سجل نموذج الاختبار، والمعرّفات الثلاثة محفوظة. |
| `save-reload-retry.json` | ضغط حفظ عمدًا كتب مرة واحدة، ثم التحديث والبحث حافظا على المعرّفات نفسها؛ لا يثبت مسار مزود حقيقي. |
| `choices-phone-390.jpg` | لقطة طويلة مقروءة للمكوّنات والأسماء والحالات والبحث في عرض الهاتف؛ من جولة المكوّن قبل إضافة غلاف التنقل إلى المحمل. |
| `choices-desktop-top-1440.jpg`, `choices-desktop-bottom-1440.jpg` | لقطتان متتابعتان للمكوّنات في عرض الحاسوب؛ تبينان الأسماء والحالات ومؤشر التركيز على البحث. |
| `choices-tablet-top-768.jpg`, `choices-tablet-bottom-768.jpg` | لقطتا عرض كامل أعلى/أسفل داخل غلاف الإدارة الفعلي، من جولتي الفحص وإعادة التصوير. |
| `navigation-phone-390.jpg`, `navigation-tablet-768.jpg`, `navigation-desktop-top-1440.jpg`, `navigation-desktop-1440.jpg` | تنظيم التنقل والبحث العربي والقائمة الجانبية، بأبعاد مؤكدة من التبويب نفسه؛ الحاسوب أعلى/أسفل. صلاحيات الغلاف بيانات اختبار، لا قبولًا لأدوار حقيقية. |
| `home-practice-phone-390.jpg` | تفاعل المراحل الحالي في بناء Next Preview المحلي، بديل سيناريو «ملاحظاتك» القديم. لا معاينة خاصة ولا كتابة حساب. |
| `responsive.json` | قياسات جولة المكوّن المستقلة: 390/768/1440، نموذج صالح ولا تجاوز لعرض المستند. |
| `verification.json` | نتيجة الفحوص وقيودها، ولا يتضمن بيانات حساسة أو تقييم جاهزية رقمي. |

فحص الالتقاط كشف صورًا طويلة مزاحة/مقصوصة عند التابلت والحاسوب؛ حُذفت، ولم تُقصّ أو تُركّب لتبدو ناجحة. بديلها لقطات عرض كاملة متتابعة. فشل التقاط طويل لاحق للهاتف لم يُستبدل بصورة فارغة؛ احتُفظ بالصورة المقروءة السابقة مع توضيح نطاقها. لم يتوفر اختبار Chrome خارجي أو جهاز مادي.

تغيير عرض المتصفح يطبّق على التبويب المختار. عند وجود تبويبات فحوص إضافية تحققنا من الأبعاد الفعلية وصححنا تسمية/التقاط صور التنقل؛ لا نعتمد على قيمة العرض المطلوبة وحدها.

قد يختلف عدّاد الحفظ بين صور جولات التصوير المنفصلة. إثبات عدم الكتابة ثم الحفظ المقصود لنفس المعرّفات هو المقارنة بين ملفّي JSON المذكورين، وليس رقمًا ظاهرًا في صورة منفردة. أُعيد تصوير أعلى التابلت من تبويب جديد بعد اكتشاف أن لقطة علوية سابقة كررت الجزء السفلي بسبب موضع التمرير المحفوظ.

فحص التعلم الإضافي استُضيف بـ`verify-learning-browser.mjs --serve` واختُبر عبر المتصفح المعتمد. ردوده المحلية معلنة، ولم تُسجل كقبول للمزود أو الاستحقاقات. لم تُختبر كل حالات الملف الآلي الأصلي في هذه الجولة.
