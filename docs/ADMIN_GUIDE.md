# دليل الإدارة — ADMIN GUIDE

لوحة الإدارة على `/admin` — تتطلب حسابًا إداريًا معتمدًا، بريد الحساب وكلمة مروره، ثم MFA بمستوى AAL2. لا يوجد بريد إدارة مشترك في متغير بيئة؛ الأدوار الفعلية محفوظة في `admin_roles` وتُراجع الصلاحية داخل الخادم وقاعدة البيانات.

## المهمة اليومية الأهم: موافقات الدفع
`/admin/payments` — حين ترفع عميلة إيصال تحويل:
1. اضغطي **عرض الإيصال** (رابط آمن مؤقت لصورة الإيصال).
2. طابقي المبلغ والاسم مع حسابك البنكي/إنستاباي.
3. **اعتماد** → يتحول الطلب إلى «مدفوع»، يُفعَّل وصول العميلة تلقائيًا (دورة/كتاب/ورشة/جلسة)، ويصلها إشعار.
4. **رفض** → اكتبي السبب (يظهر للعميلة حرفيًا) ويعود طلبها لانتظار الدفع لترفع إيصالًا جديدًا.
كل قرار يُسجَّل في سجل التدقيق باسمك.

## المحتوى
- **المنتجات** `/admin/products`: كل ما يُباع. زر «نشر/إخفاء» يتحكم في الظهور فورًا.
- **الدورات** `/admin/courses`: زر «المنهج» يفتح منشئ الوحدات والدروس. الدرس بلا فيديو يظهر بشارة «بلا فيديو» — ارفعي الفيديو إلى مخزن `course-videos` وضعي مساره في حقل الدرس.
- **الكتب** `/admin/books`: اربطي ملف PDF عبر جدول book_files (مخزن `protected-books`).
- **المقالات** `/admin/articles`: اكتبي كمسودة ثم «نشر».
- **التقييمات** `/admin/reviews`: «اعتماد» يعرضه على صفحة المنتج، «تمييز» يعرضه في الرئيسية.

## التسويق
- **العروض** `/admin/offers`: خصم بنسبة أو مبلغ، يستهدف نوع منتجات أو الكل، بنافذة زمنية — يظهر تلقائيًا في الرئيسية وصفحة الدفع مع عدّاد.
- **الكوبونات** `/admin/coupons`: كود + حدود استخدام. يُحتسب الاستخدام فقط عند اعتماد الدفع.

## العمليات
- **الطلبات** `/admin/orders`: تصفية بالحالة؛ إلغاء (قبل الدفع) أو استرداد (بعده — يسحب الوصول العام).
- **الحجوزات** `/admin/bookings`: أكّدي الجلسة (يصل إشعار للعميلة)، ثم «اكتملت» بعدها.
- **التقارير** `/admin/reports`: إيرادات ١٢ شهرًا وتقارير الدورات؛ «حفظ لقطة» يؤرشف أرقام اليوم.

## الإعدادات والنظام
- **الإعدادات** `/admin/settings`: حسابات الدفع (payment_instapay/payment_wallet/payment_bank — طريقة الدفع تختفي من صفحة الدفع إن لم تُهيّأ)، مهلة الطلبات، ومفاتيح الميزات (إخفاء ورش العمل مثلًا).
- **الأدوار** `/admin/roles` (للمالكة فقط): ادعي حسابًا جديدًا، ثم امنحي دورًا بأدنى صلاحية كافية مثل الدعم أو المحررة أو المحللة أو المدققة للقراءة فقط. يمنع النظام تغيير دورك ذاتيًا أو إزالة آخر مالكة.
- **أرشيف تسجيل الدخول** `/admin/login-history`: محاولات الدخول وMFA والجلسات والخروج مع فلترة وتصدير CSV يتطلب MFA حديثًا؛ لا يُحفظ IP أو User-Agent خام.
- **سجل التدقيق** `/admin/audit-logs`: كل عملية حساسة بهوية منفذتها — راجعيه أسبوعيًا.

## مركز التحكم الكامل — V2.7
- **إنشاء وتعديل وحذف الكتالوج:** صفحات المنتجات والدورات والكتب والورش والخدمات تحتوي الآن نماذج فعلية للسعر، السعر السابق، الوصف، الغلاف، الرابط، الترتيب، النشر، والحقول المتخصصة. الحذف يتوقف تلقائيًا إذا كان السجل مرتبطًا بطلبات تاريخية.
- **الباقات والاشتراكات** `/admin/memberships`: باقات شهرية/ربع سنوية/سنوية أو مرة واحدة، مع السعر والمدة والجلسات والمزايا والسعة وفترة البيع والنشر، بالإضافة إلى إدارة حالة اشتراك كل عميلة.
- **الجدول المتقدم** `/admin/bookings`: وقت مستقل لكل يوم، إغلاق تاريخ استثنائي أو فتحه بساعات خاصة، وحذف الاستثناء. يمكن تعديل الحجز نفسه وموعده ورابط اللقاء والحالة والملاحظات الداخلية.
- **النسخ والمراجعات:** التعديلات المهمة تحفظ النسخة السابقة في `content_revisions`، بينما يسجل `audit_logs` المنفذة والوقت ونوع العملية.
- **نصوص الصفحة الرئيسية** `/admin/settings`: حقول عربية مباشرة للعنوان والوصف والأزرار وبطاقة الصورة؛ الحفظ ينشر فورًا.
- **الرسائل والقائمة البريدية** `/admin/inbox`: قراءة، تعليم كمقروءة/تم الرد/مؤرشفة، وتفعيل أو إلغاء أو حذف الاشتراكات البريدية.
- **الوسائط** `/admin/media`: رفع حقيقي إلى مخازن Supabase المناسبة وتسجيل الأصل وحذفه من Storage والسجل معًا.
- **العروض والكوبونات:** إنشاء وتعديل وإيقاف وحذف. الكوبون المستخدم لا يُحذف حفاظًا على سلامة التقارير ويمكن إيقافه بدلًا من ذلك.
